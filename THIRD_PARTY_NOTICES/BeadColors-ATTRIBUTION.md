# BeadColors attribution

95 of the digital Perler color values in `perler_engine/assets/perler_colors.csv` (rows whose
`hex_source` column reads `beadcolors (maxcleme/beadcolors, MIT)` and whose `confidence` column
reads `community-measured`) come from the **BeadColors** project:

- Project: https://github.com/maxcleme/beadcolors
- License: MIT License, "Copyright (c) 2020 maxcleme". The full license text is in
  [`BeadColors-LICENSE.txt`](BeadColors-LICENSE.txt), copied unchanged from
  https://raw.githubusercontent.com/maxcleme/beadcolors/master/LICENSE on 25 October 2026.

The MIT License requires its copyright notice and permission notice to be included in all copies
or substantial portions of the data; `BeadColors-LICENSE.txt` is distributed for that purpose.

The BeadColors README describes its values as community contributions and does not name an
upstream source.
